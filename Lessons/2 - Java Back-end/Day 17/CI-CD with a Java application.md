## What is CI/CD?

### Continuous Integration (CI)
> [!note] **Continuous Integration** is the practice of automatically building, testing, and validating code changes as they are committed to a shared repository

**Key Principles:**
- Developers commit code frequently (multiple times per day)
- Each commit triggers automated build and test processes
- Fast feedback on integration issues
- Maintains a deployable main branch

### Continuous Deployment/Delivery (CD)

> [!info] **Continuous Deployment** automatically releases every change that passes the automated pipeline to production

> [!info] **Continuous Delivery** ensures code is always in a deployable state but requires manual approval for production releases
